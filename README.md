# Lista de Compras

App de lista de compras por categoria, com preços em reais, total do carrinho e histórico de gastos no mercado.

- Instalável no celular (PWA) e funciona sem internet.
- Os dados ficam guardados só no aparelho. Use **Salvar backup** / **Restaurar backup** para não perder nada.

Publicado com GitHub Pages a partir da branch `main`.
